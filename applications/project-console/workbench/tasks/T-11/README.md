# T-11 确认导师与校内盖章办理路径

## 任务说明

向校内负责人核实导师资格、盖章要求和实际办理路径。当前样例缺少校内负责人的确认。

## 跨任务前置

无直接前置任务。

## 交付标准

负责人和适用条件均有依据。等待回应期间可以记录已做的询问；收到有效确认后再解除阻塞。
