# 多批局部小样：制作与比较约定

2026-11-11。用户原意：先整体规划，再做多次、多样的小样，依次评判比较；基本相同的多个版本没有意义。

三批六种结构按 A/B → C/D → E/F 推进。每批保留实际源码、截图、自动交互记录及 Agent 评判；后批说明吸收了什么、仍保留什么代价。不同主题皮肤不是结构迭代。

共同任务：在同一份合成数据中找出目标的全部未完成前置；追踪一个前置，再下钻一次；返回原任务并保留筛选。补充检查长标题、多前置、已完成前置、跨项目、空结果、缺失引用与减少动态效果。

主要指标：答案是否完整；方向是否会误读；用户能否知道当前对象和原对象；返回是否恢复条件；键盘路径是否可达；在手机上是否可完成；美术是否强化了这些信息。浏览器实测按钮和状态，截图检查布局；Agent 视觉评价单独记为判断，不伪装成人类数据。

版本差异至少覆盖下列两项：信息分组、关系表达、主操作路径、上下文保留。配色、字体、装饰和间距变化本身不计入。评价可以得出暂不采用，不能所有版本都用相同理由判优。

试验页面要标明样例数据与原型身份。工具检测和源码路径保存在文档中，产品操作文案只表达用户任务。无需引导用户理解测试实现细节。
