## 范围与研究单位

- 继续首个风格实例“鹰角美术风格”，取证产品统一为终末地。优先采集 PC／鼠标键盘材料；平台不明或条件不同的材料分别标注。

## 推进顺序

1. **01—03：定位与视觉层级。** 先用 C01 校准一次同版本操作链的记录，再研究任务入口与对象身份。复盘美术重心是否与实际操作对齐，避免只抽取风格特征。
2. **04—07：比较与依赖追踪。** 研究信息密度、筛选、前置关系与跨界面连续性。比较候选机制的共性与适用条件，不因出现多次就直接认定有效。
3. **08—10：异常与复杂操作。** 用异常、影响范围与密集对象选择检验前面的解释，主动保留失败与反例。
4. **十次之后汇总。** 合并重复原则，写清条件与代价；为同一总控台任务提出两种结构不同的线框方案，再安排原型验证。汇总不是额外的第 11 次原产品案例，也不表示此次已制作原型。

默认一次推进一个主要案例。顺序可依据材料可得性调整，保留编号与变更理由；不要求把 C01 所有未知永久解决后才能研究其他主题。官方与公开操作实录均找不到所需过程时，登记具体缺口，推进下一可采集项。若替换题目，保留原编号和替换原因，不用孤立图片充数。

## 每次研究的执行与交付

**开题：** 明确用户目标、起点、完成条件、版本、平台、输入方式、熟悉程度及一个核心问题；把预期机制先记为假设。

**采集：** 找可定位来源的连续操作记录，提取必要状态。通常先检查约 4—8 个关键状态，数量随真实过程调整，不能为达标编造。重看同一录像不增加独立体验次数。

**四成分：** Key Screens、Experience Notes、Motion Specification、Interaction Flow 共用状态、转换与证据编号。没有视频时，可用有真实操作先后记录的连续截图与观察笔记表达流程；精确动效时长、缓动和输入时机需要相应连续或计时证据。未知明确写未知；没有真人原话时只记 Agent 观察。

**解释：** 建立“证据 → 可观察行为 → 候选解释 → 条件／代价／反例 → 迁移问题”的链路。每次都检查构图、字体／图像层级、色彩语义、图标与材质，以及选择和转换时视觉职责是否发生合理变化。

**产出：** 一份案例记录及来源／原始素材；有依据的候选原则；一份对总控台同一任务的局部结构草图或文字映射；明确不能迁移的部分。允许得出暂不迁移，不强凑固定数量的原则；不要求每例另建完整原型。

**复核：** 校验来源和状态对应，区分观察事实、作者声明、体验者原话、Agent 假设与已验证结果。原产品资料研究和目标原型的可用性验证分别登记。

## 完成标准与进度

当前十份资料研究均已分析，完整工作过程仍各有关键缺口，保留 `partial`；按以下原标准验收的完整案例数 **0/10**。资料报告产出数与完整交互验收数分别统计，见研究综合。

计为一份研究记录完成，至少满足：

- 工作过程及问题明确，来源能回看，版本与未知条件有登记。
- 主要状态与触发关系由真实过程材料支持，四成分对应一致；只有孤立静态图时仍为部分研究。
- 处理至少一种合理替代解释、失败条件或迁移代价，不强求人类相反评论。
- 包含美术／导视分析及对同一总控台任务的有边界映射，可以明确暂不迁移。
- 标明未验证的动效参数和体验判断。无真人验证可形成有边界的资料研究，但不能写成人类可用性验证通过。

十份记录完成不等于原则或产品已验收。十例同属一产品，也不是十份独立外部验证；仍需在总控台任务中检验可迁移性、交互可用性、视觉质量与原创性。
