# 复用前的任务简报

只在实际制作时填写，不为每条聊天生成记录。

- 用户要完成什么，怎样知道完成？原对象、当前对象及真实关系是什么？
- 哪些操作只查看，哪些会写数据？取消／冲突／撤销边界在哪里？
- 数据有何异常：多前置、共享、循环、缺失、长文本、空结果？
- 选用哪些规则 ID／版本，哪些不适用？每个决定有什么业务理由？
- 两种候选在哪些轴上不同：信息分组、操作路径、关系表达、空间层次、文字节奏、图形与材质？若只有美术不同，标成同结构视觉实验。
- 每个显著图形／颜色／表面在传达什么？移除后会损失什么？
- 不使用某个参考家族，还能怎样推导？哪些规则只适合该风格？
- 哪些证据来自文档、观察、Agent 测试与人类反馈？交付入口、验证和限制在哪里？
